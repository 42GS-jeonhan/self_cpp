다음과 같은 형태의 함수 오버로딩은 문제가 있다. 어떤 문제인지 설명.

```
int SimpleFunc(int a = 10)
{
	return a + 1;
}

int SimpleFunc(void)
{
	return 10;
}
```

A.
int형 변수 a 하나를 인자로 받는 SimpleFunc의 매개변수에 기본값이 지정되어 있음.
이 경우 SimpleFunc를 인자 없이 호출하는 경우 int a에 기본값을 사용하는 SimpleFunc(int a = 10)를 호출해야 할 지 SimpleFunc(void)를 호출해야 할 지 구별할 수 없게 됨

